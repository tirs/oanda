# OANDA Trading Bot - Render Deployment

A professional web-based OANDA trading bot with real-time dashboard, analytics, and automated trading strategies.

## 🚀 Quick Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## 📋 Prerequisites

- OANDA trading account (practice or live)
- OANDA API credentials (Access Token & Account ID)
- GitHub account
- Render account (free tier available)

## 🔧 Environment Variables Required

Set these in your Render dashboard:

```
ACCESS_TOKEN=your_oanda_access_token
ACCOUNT_ID=your_oanda_account_id
ENVIRONMENT=practice
```

## 🌟 Features

- **Real-time Dashboard**: Live trading metrics and positions
- **Position Management**: View, modify, and close positions
- **Advanced Analytics**: Performance tracking and statistics
- **Multiple Strategies**: Choose from 9+ trading strategies
- **Backtesting**: Test strategies on historical data
- **Multi-instrument Trading**: Trade multiple currency pairs
- **Risk Management**: Advanced position sizing and risk controls
- **RESTful API**: Programmatic access to all features

## 📊 Dashboard Preview

- Live P&L tracking
- Open positions management
- Recent trades history
- Performance analytics
- Strategy configuration

## 🛡️ Security

- Environment variables for sensitive data
- HTTPS by default on Render
- No API keys in code
- Practice account recommended for testing
